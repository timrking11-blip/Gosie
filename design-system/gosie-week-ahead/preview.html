02 · typography

Editorial headlines, clear UI

Fraunces + Manrope
Display · Fraunces
Make space for your week.

Manrope carries navigation, body copy, labels, and controls. Keep supporting text calm and easy to scan; use the display face for the few words that set the tone.

UI · Manrope · Fallbacks: Avenir Next, Segoe UI

Deep surfaces keep focus.

Espresso panels frame the weekend ideas and action header. Cream text, peach accents, and generous line spacing carry the hierarchy.

04 · interaction

Clear states, accessible controls

Focused

3px bronze outline with a 3px offset; keep keyboard focus visible.

Selected

Use a filled forest or peach state plus `aria-pressed`, not color alone.

Reduced motion

Decorative movement yields to `prefers-reduced-motion`.

Context scores, event names, budget, and travel in the current preview are illustrative. Preserve those disclosures wherever this sample UI is reused.
